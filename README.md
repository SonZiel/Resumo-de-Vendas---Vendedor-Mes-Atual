# 📊 Resumo de Vendas - Mês Atual

Este projeto exibe um **resumo visual e dinâmico das vendas do mês atual** de cada vendedor, mostrando informações como:

- 🧾 **Orçamentos**
- 📦 **Pedidos**
- 💰 **Vendas Líquidas**
- 🔁 **Devoluções**
- 💸 **Comissão**
- 🎯 **Progresso em relação à meta mensal**

---

## 💡 Funcionalidade

O card apresenta de forma clara e moderna o desempenho do vendedor no mês atual.  
Os valores são obtidos a partir de consultas **SQL**, processados e exibidos em uma interface criada com **HTML, CSS e JavaScript**.

Na parte inferior, é exibida a **porcentagem de progresso da meta** e uma mensagem motivacional de acordo com o desempenho.

Exemplo de mensagem:
> _"Excelente! Falta pouco pra meta!"_

>_"Continue firme! Você está no caminho certo!"_

## 🧠 Tecnologias Utilizadas

- **HTML5** – Estrutura da página  
- **CSS3** – Estilização e design responsivo  
- **JavaScript (ES6)** – Cálculos e lógica de exibição dinâmica  
- **SQL (T-SQL / Oracle)** – Consulta e processamento dos dados de vendas

## ⚙️ Funcionalidades Principais

- Exibe os **valores consolidados** de orçamentos, pedidos, vendas, devoluções e comissão.  
- Calcula automaticamente o **progresso em relação à meta**.  
- Apresenta **mensagens dinâmicas** de motivação conforme o desempenho.  
- Layout **responsivo** e com **design moderno** em formato de funil (pipeline).

---

## 📈 Exemplo de Uso

O card pode ser integrado a um **painel de controle (dashboard)** interno para a equipe de vendas.  
Cada vendedor tem seu resumo mensal atualizado em tempo real conforme os dados do sistema.
